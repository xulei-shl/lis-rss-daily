# Frontend Design Audit & Upgrade Plan

## Project Context

LIS-RSS Literature Tracker — academic RSS literature tracking system.  
**Stack**: EJS templates + vanilla CSS + vanilla JS (no framework).  
**CSS Architecture**: Well-organized with `design-system/tokens.css`, `base/`, `components/`, `pages/`.  
**Fonts**: Crimson Pro (serif heading) + IBM Plex Sans (body) + IBM Plex Mono (code) + Inter (meta/UI labels).  
**Color**: Academic blue accent `#1a4d7a` with proper light/dark mode.

---

## Part 1: AI Slop Audit — Findings

### HIGH Severity

| # | Tell | Location | Issue |
|---|------|----------|-------|
| 1 | Candy gradient badges | `daily-summary.css:467-531` | 5 decorative 135° gradients: indigo→violet, teal→green, pink→red, blue→cyan, lavender→pink. Pure AI slop — every badge screams a different color. |

### MEDIUM Severity

| # | Tell | Location | Issue |
|---|------|----------|-------|
| 2 | Inter as meta font | `tokens.css:53` | `--font-meta: 'Inter'` — the canonical AI default. Used for buttons, labels, nav, badges across the entire UI. |
| 3 | Glassmorphism | `page-header.css:15-16`, `modal.css:12` | `backdrop-filter: blur(10px)` + `rgba(255,255,255,0.9)` on header. Classic AI frosted glass. |
| 4 | Emoji in UI text | `login.ejs:27`, `error.ejs:23`, `articles.ejs:545,961`, `panel-gmail.ejs:9,192,194,197` | 📚 ❌ ✅ ⚠️ used in headings and status messages. |
| 5 | Glow effect | `daily-summary.css:54-55` | `filter: drop-shadow(...)` explicitly commented "Subtle glow for the icon". |

### LOW Severity

| # | Tell | Location | Issue |
|---|------|----------|-------|
| 6 | Springy card hover | `cards.css:19`, `home.css:30`, `search.css:220` | `transform: translateY(-2px)` on hover — universal AI "lift" pattern. |
| 7 | Login radial gradient | `login.css:18-28` | `radial-gradient(circle at center, ...)` pseudo-element background. Subtle but decorative. |
| 8 | Inline rgba shadows | Multiple files | Many hardcoded `rgba(0,0,0,0.1)` shadows instead of using tokens. |
| 9 | Glow shadow on buttons | `buttons.css:41,80` | `box-shadow: 0 4px 12px rgba(26, 77, 122, 0.25)` — colored glow shadows. |

### Intentionally Kept (Not Slop)

- **Serif headings** (Crimson Pro): Appropriate for an academic/literature tool. This is a deliberate design choice, not AI default.
- **Badges** (passed/rejected/pending): Functional status indicators with square borders, not decorative pills. Keep.
- **IBM Plex Sans/Mono**: Distinctive, well-chosen body/code fonts. Not generic.
- **Academic blue accent** `#1a4d7a`: A real, considered color — not an AI purple/indigo gradient.

## Part 2: Design Upgrade Plan

### Priority 1: Kill the Gradient Badges (HIGH impact, easy)

**File**: `src/public/css/components/daily-summary.css:467-531`

Replace 5 candy gradients with solid, muted background colors that use the existing token palette:

```css
/* BEFORE: 5 gradient backgrounds */
.badge-journal { background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); }
.badge-blog_news { background: linear-gradient(135deg, #11998e 0%, #38ef7d 100%); }
.badge-journal_all { background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%); }
.badge-search { background: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%); }
.badge-insights { background: linear-gradient(135deg, #a18cd1 0%, #fbc2eb 100%); }

/* AFTER: solid muted colors with consistent style */
.badge-journal { background: rgba(26, 77, 122, 0.1); color: var(--accent-primary); }
.badge-blog_news { background: rgba(5, 150, 105, 0.1); color: var(--green); }
.badge-journal_all { background: rgba(217, 119, 6, 0.1); color: var(--amber); }
.badge-search { background: rgba(96, 165, 250, 0.1); color: #60a5fa; }
.badge-insights { background: rgba(139, 92, 246, 0.1); color: #8b5cf6; }
```

Also add `border: 1px solid transparent` and keep existing padding/font properties. The visual differentiation comes from color, not gradient decoration.

### Priority 2: Replace Inter with a Distinctive Meta Font (MEDIUM impact, easy)

**File**: `src/public/css/design-system/tokens.css:53`, `src/views/layout.ejs:11`, `src/views/login.ejs:15`

Replace `Inter` with `DM Sans` — a geometric sans with more character, still highly legible at small sizes. It pairs well with both Crimson Pro and IBM Plex Sans.

```css
/* BEFORE */
--font-meta: 'Inter', system-ui, -apple-system, sans-serif;

/* AFTER */
--font-meta: 'DM Sans', system-ui, -apple-system, sans-serif;
```

Update Google Fonts link to load `DM Sans:wght@400;500;600;700` instead of `Inter:wght@400;500;600`.

### Priority 3: Simplify Header — Remove Glassmorphism (MEDIUM impact, easy)

**File**: `src/public/css/components/page-header.css:5-17`

Remove the frosted glass effect. Use a clean solid background with a subtle bottom border:

```css
/* BEFORE */
.site-header {
  backdrop-filter: blur(10px);
  background: rgba(255, 255, 255, 0.9);
}

/* AFTER */
.site-header {
  background: var(--bg-surface);
  border-bottom: 1px solid var(--border);
}
```

Remove the dark mode `rgba(20, 20, 20, 0.9)` override (lines 19-23) — the token `--bg-surface` already handles dark mode.

### Priority 4: Remove Emoji from UI (MEDIUM impact, easy)

Replace emoji with SVG icons or plain text:

| File | Line | Emoji | Replacement |
|------|------|-------|-------------|
| `login.ejs` | 27 | 📚 | Remove from heading, or use an inline SVG book icon |
| `error.ejs` | 23 | ❌ | Replace with SVG alert icon or just remove |
| `articles.ejs` | 545, 961 | ✅ | Replace with a small SVG check or use `✓` unicode |
| `panel-gmail.ejs` | 9 | ⚠️ | Replace with SVG warning icon |
| `panel-gmail.ejs` | 192, 194, 197 | ✅ ❌ | Replace with unicode `✓` / `✗` (already used in `settings.js`) |

### Priority 5: Remove Glow Effect (LOW impact, easy)

**File**: `src/public/css/components/daily-summary.css:52-56`

```css
/* BEFORE */
.panel-icon {
  filter: drop-shadow(0 2px 4px rgba(var(--accent-primary-rgb), 0.2));
}

/* AFTER */
.panel-icon {
  color: var(--accent-primary);
}
```

### Priority 6: Tone Down Card Hover Lift (LOW impact, easy)

**Files**: `cards.css:19`, `home.css:30`, `search.css:220`

Replace `translateY(-2px)` lift with a subtler border-color shift:

```css
/* BEFORE */
.card:hover {
  transform: translateY(-2px);
  box-shadow: 0 12px 30px -8px rgba(0, 0, 0, 0.12);
}

/* AFTER */
.card:hover {
  border-color: var(--border-strong);
}
```

Keep the shadow transition subtle if desired, but remove the lift.

### Priority 7: Simplify Login Page Background (LOW impact, easy)

**File**: `src/public/css/pages/login.css:18-28`

Remove the radial-gradient pseudo-element. The login page looks clean without it:

```css
/* DELETE the entire ::before pseudo-element block */
```

### Priority 8: Add Missing Essentials (MEDIUM impact, easy)

1. **Favicon**: Create a simple SVG favicon (book/RSS icon) and add `<link rel="icon">` to `layout.ejs`
2. **Skip-to-content link**: Add `<a href="#main-content" class="skip-link">跳转到内容</a>` at top of `layout.ejs` body, with CSS to hide it visually until focused
3. **404 page**: Create `src/views/404.ejs` with a helpful "page not found" message, styled consistently with `error.ejs`

### Priority 9: Inline Shadow Cleanup (LOW impact, tedious)

Audit all hardcoded `rgba(0,0,0,...)` shadow values and migrate to token references where possible. Not critical — the tokens already exist and most components use them. Focus on the most visible ones (buttons, cards).
