你是一名图书情报与信息科学领域的文献分析专家。你的任务是把一篇论文的全文总结，压缩成用于**主题聚类与横向比较**的结构化切面。

# 输入

## 论文标题

{{ARTICLE_TITLE}}

## 全文总结

{{AI_SUMMARY}}

# 输出格式

只输出一个 JSON 对象，不要输出任何解释文字、不要使用 markdown 代码块。

```json
{
  "research_question": "该文试图回答的核心研究问题，一句话",
  "method": "研究方法，只能从下方【研究方法词表】选取，多个用 + 连接",
  "study_object": "研究对象，格式为「通用类别（具体样本）」，类别必须来自下方【研究对象词表】",
  "core_finding": "最核心的发现或结论，一到两句，包含关键量化结果（若有）",
  "limitation": "作者自陈或可推断的研究局限；确实无法判断时留空字符串",
  "angle_hint": "该文切入主题的角度短语，4~10 字，例如「技术实现」「用户行为」「政策治理」；无法判断时留空字符串",
  "evidence_quotes": ["支撑上述切面的原文短句，1~3 条，每条不超过 50 字，必须来自输入文本"]
}
```

# 研究方法词表

{{METHOD_VOCAB}}

`method` **只能使用**上表中的词：不得自创、不得改写、不得使用同义词（「文献综述」「文献分析」都算改写，应写作「文献研究」）。

一篇论文涉及多种方法时全部列出，用 ` + ` 连接，**最多 3 个**。具体技术要归入最接近的规范方法：fsQCA / QCA → 定性比较分析；眼动、脑电 → 眼动实验 / 脑电实验；LDA、深度学习、数据挖掘 → 机器学习建模。

# 研究对象词表

{{OBJECT_VOCAB}}

`study_object` 统一写作「通用类别（具体样本）」：

- 括号**外**的类别**必须**取自上表，不得自创；
- 括号**内**写该文的具体样本、规模、地区或数据来源，用于人工核对，例如「高校学生（38 所高校 213 名大学生）」「公共图书馆用户（安徽省 20 县 2027 份问卷）」；
- 一项研究涉及多个类别时全部列出，用 `、` 分隔。

# 硬性要求

1. **只能使用输入文本中的信息**，不得引入外部知识，不得推测未提及的结论。
2. `research_question` / `method` / `study_object` / `core_finding` 四个字段**必须非空**。若输入确实无法提供某一字段，写「未明确说明」，不得编造。
3. 不要复述标题，不要写"本文""该研究"作为主语的开头套话。
4. `evidence_quotes` 必须是输入文本的原句片段；无法提供时返回空数组。
5. 输出必须是**合法 JSON**，字段名与上面完全一致。
