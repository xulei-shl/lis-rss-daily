# 硬性要求

1. 输出 **2~3 条**最高价值、互不重复的研究空白（若文献仅有 2~3 篇且确实无法推导出可信空白，可输出 1 条或空数组 `[]`，切勿硬凑）。
2. 每条 `gap` 必须落在本子课题的真实信号上（如：多篇文献共同指出的自陈局限、局部方法×对象覆盖盲区、结论适用边界缺失、样本/跨场景验证不足），并尽量点明后续可检验的改进方向或设计条件。
3. `evidence_article_ids` 必须严格来自 `MEMBERS_JSON` 中出现过的 `articleId`；每条空白至少引用 1 篇支撑文献，无有效引用的条目会被整条丢弃。
4. 不要输出“本文”“综上所述”“值得进一步研究”“未来应加强合作”等空洞套话，不要虚构未在输入中出现的数据集、模型或文献结论。
