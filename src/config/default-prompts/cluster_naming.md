# 输入

## 该簇内文献的切面列表（研究问题 / 方法 / 研究对象 / 核心发现）

{{FACETS_JSON}}

# 输出格式

只输出一个 JSON 对象，不要输出解释文字、不要使用 markdown 代码块。

```json
{
  "name": "主题名称，8~20 字，名词短语，概括该簇共同关心的研究议题",
  "keywords": ["3~5 个核心词"],
  "description": "一句话说明该主题的范围（50 字以内）"
}
```

# 硬性要求

1. 名称必须**概括簇内共同点**，而不是复述某一篇文献的标题。
2. 名称使用领域内规范表述，不要生造缩写。
3. `keywords` 每个 2~8 字，为可检索的领域术语。
4. 名称与关键词中**不得出现**任何 `article_id`、编号、括号内的样本量等元信息。
5. 输出必须是合法 JSON，字段名与上面完全一致。
