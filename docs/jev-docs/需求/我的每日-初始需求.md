## 基本需求描述
项目新增用户管理模块，admin用户可以在`/settings`页面模块的`维护`类别下新增用户管理功能。admin可以新增、删除、修改用户信息。
非admin的登录用户除了复用已有的guest账号类别的功能外，新增一个`我的每日`页面，这个页面是一个jev检索页面，根据用户在`/topics`页面中新增的主题领域与关键词，利用jev模型对每日新增的所有文章进行评分打标过滤，按照从高到底排序展示。评分低于某个值的条目用灰色显示。

页面顶部也有一个搜索框，用户可以在搜索框中输入关键词，当日的所有文章进行评分过滤，重新排序显示。评分低于某个值的条目用灰色显示。因为每日最多只有几十篇文章，可以直接所有文章并行调用jev进行评分。检索结果动效显示，评分出来的结果就立刻根据评分排序展示，因为结果完成有先后，这个排序是动态调整，知道全部结果完成。

jev的资料见 docs\jev-docs\官方资料，jev如何使用的参考的项目 docs\jev-docs\projects。

jev支持noul，choice，score三种问题模式。这个个性化检索要充分合理的选用三种模式，实现用户自定义的检索需求。
