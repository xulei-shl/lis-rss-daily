# 多用户角色扩展方案 — 文章查询与抓取重构

## 1. 核心模式替换

所有文章查询将 4 路 OR JOIN 替换为 `user_articles` JOIN。

### 旧模式

```typescript
// 4 路 OR JOIN，跨越源表查询用户可见文章
db.selectFrom('articles')
  .innerJoin('rss_sources', (j) => j
    .onRef('articles.rss_source_id', '=', 'rss_sources.id')
    .on('rss_sources.user_id', '=', userId))
  .leftJoin('journals', (j) => j
    .onRef('articles.journal_id', '=', 'journals.id')
    .on('journals.user_id', '=', userId))
  // ... 4 路 OR 逻辑
```

### 新模式

```typescript
db.selectFrom('articles')
  .innerJoin('user_articles', (j) => j
    .onRef('user_articles.article_id', '=', 'articles.id')
    .on('user_articles.user_id', '=', userId))
  .selectAll()
```

## 3. 文章抓取流程

### 抓取后关联步骤（新增）

```typescript
async function linkArticlesToSubscribedUsers(articleIds: number[], sourceType: string, sourceId: number) {
  // 1. 查询该源的所有订阅用户
  const subscriptions = await db
    .selectFrom('source_subscriptions')
    .select('user_id')
    .where('source_type', '=', sourceType)
    .where('source_id', '=', sourceId)
    .execute();

  // 2. 为每个订阅用户创建 user_articles 记录
  const values = subscriptions.flatMap(sub =>
    articleIds.map(articleId => ({
      user_id: sub.user_id,
      article_id: articleId,
      filter_status: 'pending',
      is_read: 0,
    }))
  );

  if (values.length > 0) {
    await db.insertInto('user_articles')
      .values(values)
      .onConflict((oc) => oc.doNothing())  // 已存在的忽略
      .execute();
  }
}
```

### 完整抓取流程

```
触发抓取（用户 A 操作）
  → 解析/爬取得到文章列表
  → saveArticles() 去重保存（URL / title_normalized）
  → 对每篇新文章：INSERT INTO articles
  → linkArticlesToSubscribedUsers(articleIds, sourceType, sourceId)
     → 关联给所有订阅用户
  → triggerAutoFilter()
     → 只对当前触发用户 A 执行过滤
     → 其他订阅用户保持 pending
```

### 源创建时自动订阅

```typescript
async function createSource(userId: number, sourceData: SourceData) {
  // 1. 检查是否已存在同标识源
  const existing = await findExistingSource(sourceData);
  if (existing) {
    // 2. 已存在 → 自动创建订阅
    await db.insertInto('source_subscriptions')
      .values({ user_id: userId, source_type: sourceData.type, source_id: existing.id })
      .onConflict().doNothing()
      .execute();
    return existing;
  }
  // 3. 不存在 → 创建新全局源
  const newSource = await db.insertInto(sourceTable)
    .values({ ...sourceData, user_id: userId })
    .returningAll()
    .executeTakeFirstOrThrow();
  // 4. 自动订阅
  await db.insertInto('source_subscriptions')
    .values({ user_id: userId, source_type: sourceData.type, source_id: newSource.id })
    .execute();
  return newSource;
}
```
